# Agent 实习准备：第 1 周学习任务

计划日期：2026-10-28 起，实际开始日期可顺延。状态：全部待完成。目标：建立可独立阅读、编写、调试和解释 Python 代码的能力，为第 2 周学习后端做准备。每天约 4 小时；遇到课业冲突可顺延，验收标准不随日期变化。

## 使用 AI 的练习方式

每个编程任务先独立尝试 30–45 分钟，可查官方文档和自己做的笔记。卡住时先请 AI 解释概念、指出报错或给提示，再自己实现；之后逐行解释代码、独立完成一次小修改并运行测试。训练阶段这样做是为了掌握能力，不是禁止项目中使用 AI。

## 本周项目：JSON 任务统计器

建议目录：`projects/01-task-stats/`。数据样例：

```json
[
  {"title": "复习 Python", "category": "学习", "done": true},
  {"title": "做算法题", "category": "学习", "done": false},
  {"title": "整理房间", "category": "生活", "done": true}
]
```

最低功能：从文件读取任务；统计总数 3、完成数 2；按类别统计学习 2、生活 1。根节点不是数组、缺少字段、字段类型不对、JSON 格式错误和文件不存在时应给出明确错误。空列表应能正常统计。

## 每天任务

### Day 1：摸底与环境（4 小时）

1. 30 分钟：检查 Python 和 Git 的版本，创建项目目录与虚拟环境；在 README 中记下使用的系统、Python 版本和启动方式。不提交虚拟环境目录。
2. 45 分钟：尽量不借助 AI 完成两个小练习。A：给定 `[3, 5, 8, 10]`，写函数返回偶数列表，预期 `[8, 10]`。B：给定上面的 3 条任务，写函数返回完成任务数，预期 `2`。允许查文档；不会就记录卡在哪里，不必为了通过而看答案。
3. 60 分钟：看 [Hello-Agents](https://datawhalechina.github.io/hello-agents/) 关于智能体、模型和工具的入门内容；用自己的话写 5–8 句总结。
4. 60 分钟：手写任务样例 JSON，练习 Python `json` 模块读取文件，并打印读取结果；尝试不存在的文件和格式错误的 JSON，观察报错。
5. 45 分钟：完成 1 道适合自己的算法题，最后记录今天完成内容、卡点、是否借助 AI。

Day 1 验收：能说明 list、dict、函数和 JSON 文件在练习中分别发挥了什么作用；能告诉我你自己完成的部分和卡住的部分。未完成也如实记录。

### Day 2：统计核心

45 分钟复习函数、循环、字典和类型；120 分钟编写纯函数统计总数、完成数和类别；45 分钟自己准备正常及空列表输入并检查结果；30 分钟算法练习。完成后在 README 写运行示例。

### Day 3：文件、错误与调试

45 分钟学习文件读取、异常；120 分钟把统计函数接入本地 JSON 文件；45 分钟处理文件不存在、JSON 格式错误和字段错误；30 分钟复盘一个真实错误及定位过程。

### Day 4：测试

45 分钟学习 pytest 基础；120 分钟为正常输入、空列表、无文件、非法 JSON、缺字段和类型错误编写测试；45 分钟调试失败的测试；30 分钟算法练习。确认测试输出后再提交。

### Day 5：HTTP 与后端预热

60 分钟理解客户端、服务端、HTTP 请求/响应、状态码和 JSON；90 分钟阅读 [Hugging Face Agents Course Unit 1](https://huggingface.co/learn/agents-course/en/unit1/introduction) 的 Agent 和工具部分；60 分钟写下模型、工具、工具返回结果之间的关系；30 分钟复盘。第一周不需要付费 API。

### Day 6：独立修改与 Git

90 分钟尽量不借助 AI 增加完成率字段，空列表完成率约定为 0；60 分钟补充测试并运行；60 分钟整理 README、`.gitignore`、示例数据和使用说明；30 分钟查看 Git 改动，确认没有密钥和私人数据后提交。

### Day 7：复盘与面试表达

60 分钟重看代码；60 分钟尝试脱离代码讲解输入、输出、数据结构、异常处理和测试；60 分钟复习 2 道算法题或排查本周薄弱点；60 分钟整理学习记录。向指导老师提交运行截图或终端文本、仓库代码链接及困难清单。

## 第一周验收

- 程序对样例输出总数 3、完成数 2、分类学习 2 和生活 1；空列表与错误输入有预期行为。
- 自动化测试能够运行，并包含正常、空列表、无文件、非法 JSON、缺字段与类型错误。
- 能解释主要代码，能独立完成一次小修改，说明至少一次排错过程。
- README 包含运行方法、测试方法、数据格式和已知限制；只提交自己有权分享的数据。

## 后续调整

第 2 周开始补 HTTP、FastAPI 和简单接口，同时学习模型 API 基础；独立编码练习贯穿每周。先做单 Agent，再做 RAG 与评测，最后做可展示的完整项目。关注岗位可从准备阶段开始，成熟后提前尝试投递，不把 2 月作为唯一窗口。
