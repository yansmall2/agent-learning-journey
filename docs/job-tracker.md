# 岗位研究和投递记录

目前未核验具体粤港澳在招 Agent 实习。每周到企业官方招聘渠道核对发布日期、职位状态和入职条件，也可通过公开招聘平台发现线索，再回官方渠道核实。关键词：`AI Agent 实习`、`大模型应用开发实习`、`LLM engineer intern`、`RAG`、`智能体`；搜索深圳、广州、珠海、香港及远程岗位。

可从 [腾讯招聘](https://careers.tencent.com/)、[阿里巴巴招聘](https://talent.alibaba.com/)、[华为招聘](https://career.huawei.com/) 和 [字节跳动招聘](https://jobs.bytedance.com/) 等官方入口查找；页面可用性和在招岗位需自行实时核验，不代表这些公司当前有匹配岗位。

每条岗位记录：

- 公司 / 岗位 / 城市：
- 官方链接 / 查看日期 / 是否仍开放：
- 学历、毕业时间、每周天数、实习时长、工作资格：
- 必须技能 / 加分项：
- 我的证据与差距：
- 下一步 / 投递日期 / 反馈 / 复盘：

先收集 10 条可核验的目标 JD，统计反复出现的技能；样本不足或岗位已关闭时标明，不把技能清单当作统计结论。简历和个人敏感信息应保存在安全位置，公开仓库仅放脱敏记录。
