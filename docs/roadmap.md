# 面向 Agent 开发实习的学习路线

## 目标与假设

目标：能独立实现、解释并评估一个有工具调用和知识检索的 Agent 应用，具备 Python、工程基础、面试表达能力。按 2026-10-28 起、2027 年 2 月前后重点投递、2028 年 6 月毕业、每天至少 4 小时制定。已有项目经验但编程常依赖 AI：重点训练独立拆解、实现、调试和讲解，再用 AI 做反馈。岗位可能提前开放：从第 3 周开始搜集并持续投递合适岗位，不等 2 月才开始关注。

实习可入职时间、每周天数、持续月份、毕业时间，以及香港地区工作资格以岗位及官方政策为准，先记录再筛选。

## 能力优先级

1. **必须练会**：Python（函数、类、异常、文件、虚拟环境、类型提示）、Git、HTTP/JSON、SQL 基础；能读文档、定位错误并写测试。
2. **应用核心**：Prompt、结构化输出、模型 API、tool/function calling、RAG（分块、embedding、召回、重排、引用）、Agent 循环与状态、错误恢复。
3. **工程和评测**：FastAPI、配置与密钥管理、日志、超时重试、测试，检索及回答评测、延迟与成本；能讲清取舍。
4. **面试基础**：数组、哈希、双指针、二叉树、图/搜索；计算机网络、数据库和操作系统常见问题。每周持续练习，基础不足就减小项目范围。
5. **进阶加分**：LangGraph、MCP、部署、异步/并发、模型原理与微调。优先做好一个可靠作品，再扩展；不要求全部掌握。

这些是根据公开材料和项目实践归纳的训练假设，不代表已核验粤港澳实习岗位清单。一个可查的行业参考是 [Traveloka 招聘帖](https://github.com/ruanyf/weekly/issues/12009)：其中 Agent 相关岗位列出 Python、工具调用、检索、RAG、评估和稳定性；这是 2026 年 10 月的全职高级岗位，不能当作本地实习的直接证据。用 [岗位记录](job-tracker.md) 补充真实 JD 并调整权重。

## 14 周里程碑

| 时间 | 重点 | 必须交付和验收 |
| --- | --- | --- |
| 第 1–2 周 | Python、Git、HTTP/JSON、LLM 基础概念 | 完成第一周练习；自己写一个读取 JSON 的命令行程序并附测试；能解释 token、上下文、温度和幻觉 |
| 第 3–4 周 | Prompt、模型 API、工具调用；开始收集 JD | 写出无框架的工具调用循环：参数校验、超时/错误处理、最大步数；用模拟模型/工具测试，无密钥也能运行 |
| 第 5–6 周 | RAG 基线 | 本地文档入库，分块、检索和带来源的回答；先做简单基线，记录至少 20 条人工核验问题和失败样例 |
| 第 7–8 周 | Agent 主项目第一版 | 将检索做成工具，支持多步问题、无答案与失败处理；演示正常路径和边界情况 |
| 第 9–10 周 | 评测与工程化 | 固定测试集并对比基线/改进；报告检索命中、回答及引用质量、延迟和成本，加入 API、日志和测试 |
| 第 11–12 周 | 求职材料、补基础 | README、架构图、复现步骤、演示和真实结果；准备一页简历、项目讲解；针对 JD 查缺补漏 |
| 第 13–14 周 | 模拟面试与投递 | 完成项目追问、Python/算法/八股复盘；针对岗位改简历、记录投递和复盘，持续迭代 |

每天约 4 小时的参考分配：90 分钟独立编码和调试、45 分钟课程或文档、60 分钟项目、30 分钟算法或基础、15 分钟复盘；一周约 28 小时。岗位研究可替换部分复盘或课程时间。按精力调整并留出休息；课程不必全部看完，每个阶段先完成最小作品。时间不足时优先 Python、工具调用、RAG 和可验证项目，再缩减框架与进阶选修。

使用 AI 时：先独立思考和尝试，记录思路与错误；遇阻可请求提示、解释或代码审查，再自己实现并测试；对于 AI 提供的代码，逐行理解并尝试脱离答案重写。训练任务不以禁止工具为目的，真实工程仍可以合理使用 AI。

## 验收与记录规则

- 每周记录投入时间、可运行命令、实际结果、卡点、下一步；不会的内容如实写明。
- 指标先定义口径和数据来源，再运行并记录结果，不预填成绩。评测集与开发样例分开，保留无答案和检索失败案例。
- 模型调用可能需要付费服务、密钥或可用的本地模型；先使用模拟接口完成工程基础，不把密钥提交到 Git。
- 不承诺 offer；用实际岗位反馈、面试和测评结果持续修正路线。
