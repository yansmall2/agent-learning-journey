# 第一周：从 AI 辅助转向能够独立实现

按每天约 4 小时规划，共约 28 小时；可根据课程、精力和实际进度调整。保留休息时间。所有事项完成后再勾选，不把计划当作已完成的成果。遇到困难时记录错误和尝试（删除隐私与密钥）。

## 第一天：诊断与学习记录（约 4 小时）

1. **独立诊断（45 分钟）**：不让 AI 代写，可查官方文档，自己尝试写函数 `summarize(records)`。输入是形如 `[{"topic": "Python", "minutes": 60}, {"topic": "Agent", "minutes": 30}, {"topic": "Python", "minutes": 20}]` 的列表，返回每个主题的总分钟数；空列表返回空字典。补充对缺失字段、非数字或负数时长的处理，说明你的选择。能做多少做多少，不以完成为门槛。
2. **代码检查（45 分钟）**：运行正常、空列表和错误输入；记录实际结果，并尝试解释函数、循环、字典和异常处理。不知道也如实写。
3. **补缺（60 分钟）**：依据错误阅读 [资源清单](resources.md) 中的 Python-100-Days 对应章节，再独立修改一次。
4. **算法（30 分钟）**：手写一道简单的哈希表问题，说明时间和空间复杂度；卡住可先看提示。
5. **项目盘点与复盘（60 分钟）**：列出做过的项目、自己负责的部分、AI 帮助的部分以及最不熟悉的代码；在学习日志中记录诊断结果和疑问。公开仓库不要写个人敏感信息或密钥。

## 第 2–7 天

| 天数 | 约 4 小时的重点 | 交付 |
| --- | --- | --- |
| 第 2 天 | Python 函数、字典、文件与异常；动手读写 JSON；算法练习 | 自己写一个能读取和写入 JSON 的小程序，记录出错时的行为 |
| 第 3 天 | 设计学习记录命令行程序；拆分输入校验、存储、汇总；开始实现 | 在 `exercises/week01/` 写代码与设计说明 |
| 第 4 天 | 完成记录、列出及汇总；处理空主题、非数字或负数时长 | 程序可以通过命令行运行，附使用说明 |
| 第 5 天 | 使用标准库 `unittest` 写至少 3 个正常和错误测试；调试失败 | 实际运行测试并记录测试数和结果 |
| 第 6 天 | Git 的 status、diff、commit；观看 Prompt 入门；解释 token、上下文、temperature 和幻觉 | 检查敏感信息，提交练习；写自己的 LLM 概念例子 |
| 第 7 天 | 不看原代码重写核心汇总函数；练习口头讲解；复盘算法和一周卡点 | 完成学习日志，列出不熟练的部分及第二周目标 |

每天可用约 30 分钟练算法；如果当天项目遇到困难，优先解决问题，不必机械完成时长。不会的地方可以用 AI 请求提示或解释，但先自己尝试，最后能独立解释和重新实现关键逻辑。

验收：别人可以按 README 运行程序和测试；测试确实执行且通过；你能解释关键数据结构、一次错误的定位过程和 Git 提交。第一周不需要付费模型或复杂框架。
