# 第一周：搭建 Python 基础并留下第一份证据

按约 15 小时规划；实际可拆分到 7 天。尚未完成的项目不要打勾。遇到困难时保存错误信息（注意删除隐私和密钥），带上已尝试的方法一起讨论。

1. **盘点（1 小时）**：记录能投入的时间、毕业时间、目标入职和每周可实习天数；不确定的标“待确认”。用 Python 写一段 10 行左右自我介绍程序，运行并记录结果。
2. **Python 补缺（4 小时）**：使用 [资源清单](resources.md) 中的 Python 课程，重点练列表、字典、函数、异常和文件；每个主题自己写一个小例子。
3. **完成练习（5 小时）**：在 `exercises/week01/` 自己实现一个命令行学习记录程序。输入日期、主题和时长，写入本地 JSON 文件；支持列出记录和汇总时长；空主题、非数字或负数时长要有清晰错误。写至少 3 个自动化测试，包含正常和错误情况。可用 Python 标准库 `unittest`，不要求安装第三方库。
4. **Git（2 小时）**：查看 `git status` 和 `git diff`，确认没有敏感数据；提交自己的练习与说明。上传前确认远程仓库和分支。不要提交本地数据中的隐私、密钥或虚拟环境。
5. **认识 LLM（2 小时）**：看资源清单中的 Prompt Engineering 入门；用自己的话写 token、上下文窗口、temperature、幻觉各是什么，给每项一个例子。不需要死记 API 调用格式。
6. **复盘（1 小时）**：按 `journal/template.md` 新建日志，写运行命令、通过的测试数、不会的问题和第二周的目标。

验收：别人从 README 可以知道如何运行程序和测试；测试确实执行且通过；你能口头解释数据结构、异常处理和一次 Git 提交。第一周不用调用收费模型，也不用搭建复杂框架。
